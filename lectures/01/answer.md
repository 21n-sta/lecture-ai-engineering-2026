# 第1回 解答

## 演習

- 講座に固有の質問（宿題の3レベル）へのモデルの回答（要約でよい）： マスト/発展/チャレンジ
- 用語集の正しい意味と比べて気づいたこと：複数の意味で3レベルを回答していたが，全て間違っていた
- 表示できたトークン数（入力 / 出力）：(21 / 580)

## 宿題

- 取り組んだレベル：基礎 
- やったこと：モデル・temperatureを切り替えて出力を確認した
- 結果：モデルを変更すると，回答の長さや時間が変化した．temperatureを変えると回答の精度が悪くなった．
- 気づき・疑問：geminiのも出るだけでなくchatgptやclaudeなどを使うとどうなるのか気になった．

- 取り組んだレベル：実装
- やったこと：uv run python -m app.ask --interactiveで対話モードになり，直前までの会話履歴をモデルに渡して質問することが出来るようにした．トークン数削減のために10往復で一回内容を要約するようにした．
- 結果：なまえを適当に教えてそれを元にニックネームを作らせることに成功した．
- 気づき・疑問：どこまでの長さの文脈を保持できるかが気になった．


- 取り組んだレベル：発展
- やったこと：応答時間を表示させる関数を追加し，同じ質問を複数のモデルで行なった． 
- 結果：無料枠では利用できないモデルが多いことや，良いモデルは応答時間が長い事がわかった．
- 気づき・疑問：有料枠のマルチモーダル生成モデルなどの使い方が気になった．
